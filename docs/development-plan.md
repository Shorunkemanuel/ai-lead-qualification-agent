# Development Plan

## Phase 1 — Foundation
- Initialize repository.
- Create backend/frontend shells.
- Configure environment.
- Create database schema.
- Add health endpoint.

## Phase 2 — Lead Engine
- CSV import.
- Lead CRUD.
- Normalization.
- Scoring.
- Qualification.

## Phase 3 — Agent
- Nebius provider.
- Nemotron integration.
- Structured outputs.
- Agent orchestration.
- Agent-run logging.

## Phase 4 — Outreach and Approval
- Draft generation.
- Edit/regenerate.
- Approval state machine.
- Execution log.

## Phase 5 — Demo
- Seed realistic demo data.
- Polish dashboard.
- End-to-end golden path.
- Tests.
- Deployment.
- README.
- Demo video.

## Engineering rule

Build the golden path first. Do not spend early time on secondary integrations or visual polish that does not improve the core demonstration.
