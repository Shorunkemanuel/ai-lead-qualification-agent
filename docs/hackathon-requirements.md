# Hackathon Requirements

## Nebius x NVIDIA Global AI Hackathon

The submitted application must satisfy the hackathon's current rules at submission time.

Project requirements to track:

- Working software app running on Nebius Token Factory or Nebius AI Cloud.
- Use at least one NVIDIA open-source model.
- Public source repository.
- Open-source license.
- README with setup/use information.
- Public demo video under the stated time limit.
- Clearly explain Nebius and NVIDIA model usage.
- Explain significant updates if an existing project is submitted.

## Project evidence

The final README and demo should explicitly show:
1. Nebius Token Factory configuration.
2. NVIDIA Nemotron model used.
3. Real inference call.
4. Agent workflow.
5. Human approval boundary.
6. Working application.

Re-check official rules immediately before submission because hackathon requirements and platform capabilities can change.
